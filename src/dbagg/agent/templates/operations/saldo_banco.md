# Operación seleccionada: saldo_banco
- saldo_banco: saldo actual de una cuenta de banco o efectivo, con banco tal como la nombran; nunca
  customer ni entidad. Solo el saldo actual, sin período.
Ejemplo (saldo_banco): «¿Cuánto hay en la cuenta Demo?» → consultar_negocio(operation="saldo_banco",
  banco="Demo").
