# Operación seleccionada: ventas
- ventas: ventas globales en pesos y toneladas contra el período anterior o, con
  comparar=anio_anterior, contra las mismas fechas del año anterior. Las ventas a un cliente
  concreto no tienen operación: usa fuera_alcance.
Ejemplo (ventas): «¿Cómo van las ventas de maíz esta semana?» → consultar_negocio(
  operation="ventas", producto="maíz", period="esta_semana").
